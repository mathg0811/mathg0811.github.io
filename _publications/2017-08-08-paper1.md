A smartphone-based portable microscope enabling single-shot bright-field, dark-field, and differential phase contrast imaging of transparent specimens. Multi-contrast imaging is achieved using a patterned color micro-LED array and a color image sensor. A custom smartphone module and Android app perform image acquisition, computation, and real-time display.
